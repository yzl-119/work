### 研究问题

管理者短视（managerial myopia）是典型的**潜构念**，无法直接观测。本文用年报
"管理层讨论与分析"（MD&A）中的语言证据构造其文本测度，并检验：

- **H1**：管理者短视程度越高，企业长期投资强度越低
- **H2**：行业竞争程度强化上述负向效应
- **H3**：该效应在非国有企业、非高技术行业中更显著

## 四、核心结果（模拟数据）

> ⚠️ **以下结果基于教学演示用模拟数据集，用于验证方法流程，不构成任何实质性结论。**

### 主效应（H1）

| 模型 | Myopia 系数 | N | Adj. R² |
|---|---|---|---|
| 年度固定效应 | **−0.00352***（t = −23.09） | 4800 | 0.173 |
| 双向固定效应 | **−0.00128***（t = −4.05） | 4800 | 0.211 |

### 调节与异质性

| 检验 | 结果 |
|---|---|
| H2 交互项 `Myopia × Competition` | **−0.00493***（t = −5.86），竞争越激烈抑制越强 |
| H3a 国企 vs 非国企 | 国企 −0.00077（n.s.） vs **非国企 −0.00152***（t = −4.07） |
| H3b 高技术 vs 非高技术 | 高技术 −0.00091（n.s.） vs **非高技术 −0.00144***（t = −3.91） |

### 稳健性（五项检验全部方向一致）

| 检验 | 系数 |
|---|---|
| 滞后一期解释变量 | **−0.00079**（t = −2.22） |
| 行业 × 年度固定效应 | **−0.00353***（t = −23.12） |
| 剔除 2018 年样本 | **−0.00142***（t = −3.87） |
| 未缩尾测度 | **−0.00129***（t = −4.14） |
| 工具变量 2SLS（行业—年度均值） | **−0.00311**（p = 0.025） |

### 信效度

| 检验 | 结果 |
|---|---|
| 聚合效度 | 与 LDA 主题测度 r = **0.450**（p<0.01） |
| 区分效度 | 与 Size / ROA / Lev / Growth 相关系数均 < 0.03 |
| 预测效度 | β = **−0.00353**（t = −23.10） |
| 方差分解 | 企业间方差占比 **77.7%** |

## 六、如何换成真实数据

只需改动三处，其余代码无需修改：

1. **语料**：把 `data/raw/mda/` 替换为从巨潮资讯网下载、已抽取 MD&A 章节的
   年报文本（文件名格式 `{股票代码}_{年度}.txt`，与 `data/raw/firm_financial_panel.csv`
   中的代码一致）。
2. **面板**：把 `data/raw/firm_financial_panel.csv` 替换为从 CSMAR 下载的
   公司—年度财务与治理数据。
3. **词典**：如需改用其他构念（风险、韧性、数字化转型），只需替换
   `data/dictionary/myopia_dict.txt` 并在论文中说明词表来源与理论依据。

然后依次运行 `code/step1` 至 `code/step7`。

> 合规提示：抓取年报请遵守目标网站 `robots` 协议、控制请求频率；
> 正式研究中须在论文"数据来源"小节标注数据库、抓取时间与样本筛选规则。

## 七、三条速记（来自方法预备课）

1. **测度即代理** —— 你说的"短视""创新""风险"都不是直接观测的，论文里必须解释代理得合不合理。
2. **流程要留痕** —— 每一步的数据来源、参数、脚本都要保存；评审的第一反应是"能不能复现"。
3. **效度不能省** —— 没有信效度检验的测度，在评审眼里等同于"自造指标"。
