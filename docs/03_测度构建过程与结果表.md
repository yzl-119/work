# 测度构建过程与结果表

> 对应课件要求：**测度结果表**——"企业-年份面板 CSV 或 Excel"。

## 1. 一句话说明

把 43 词短视词典在年报 MD&A 中"盖章计数"，除以该文本有效词数并乘以 100，
即得到企业—年度层面的管理者短视测度，与财务/治理数据合并后形成可直接回归的面板。

## 2. 五步过程参数一览（复现所需全部信息）

| 步骤 | 关键参数 | 取值 |
|---|---|---|
| ① 语料获取 | 文本源 / 样本区间 | 年报 MD&A / 2018—2023 |
| ① 语料获取 | 样本量 | 800 家公司 × 6 年 = 4800 篇 |
| ② 文本预处理 | PDF 解析 | PyMuPDF（演示语料为 txt，代码保留分支） |
| ② 文本预处理 | 分词模式 | jieba **精确模式**（`cut_all=False`） |
| ② 文本预处理 | 停用词 | 通用 + 财经历 + 自定义，合计 **190 词** |
| ② 文本预处理 | 词长过滤 | 丢弃单字词 |
| ③ 特征提取 | 词典规模 | **43 个短期视域词** |
| ③ 特征提取 | 词向量（对照） | LSA/SVD，64 维（Word2Vec 分支可选） |
| ③ 特征提取 | LDA（对照） | K ∈ {5,8,10,12,15}，**选定 K=15**，困惑度 105.58 |
| ④ 指标构建 | 分母口径 | 去停用词后的有效词数 |
| ④ 指标构建 | 缩尾 | 1% / 99% 分位 |
| ⑤ 信效度检验 | 检验项 | 内容 / 聚合 / 区分 / 预测效度 + 条件均值 + 方差分解 |

## 3. 最终结果表 `panel_measure.csv` 字段说明

| 字段 | 含义 |
|---|---|
| `stock_code` / `year` | 公司代码 / 会计年度（面板主键） |
| `industry` / `soe` / `hitech` | 行业 / 产权性质 / 技术属性 |
| `Myopia` | **核心测度**：词典命中数 ÷ 有效词数 × 100（已缩尾） |
| `myopia_raw` | 未缩尾原始测度（用于口径稳健性检验） |
| `dict_hits` / `total_tokens` | L1 原始计数 / 分母（用于复算与透明化） |
| `LongInv` | 被解释变量：长期投资强度 |
| `Size` `Lev` `ROA` `Cash` `Growth` `Age` `Board` `Dual` `Big4` `TobinQ` | 控制变量 |
| `Competition` | 调节变量：行业竞争程度（1−HHI） |
