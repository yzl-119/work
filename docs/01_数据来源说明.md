# 数据来源说明

> 对应课件要求：**数据来源说明**——"一句话说明每个文件的来源与处理步骤"。

## 1. 一句话总览

本研究的实证部分使用**模拟数据集**（由 `code/step0_generate_demo_data.py` 按固定随机种子
`SEED=20260101` 生成），用于演示"从文本到变量"的完整可复现流程；正式研究请替换为下述
真实数据源。

## 2. 文件清单

| 文件 / 目录 | 内容 | 来源与处理步骤 |
|---|---|---|
| `data/raw/mda/*.txt` | 800 家模拟上市公司 × 2018—2023 年共 4800 篇"管理层讨论与分析"文本（平均 1990 字符/篇） | 由 step0 生成；真实研究中对应**巨潮资讯网**年报 PDF 中"第三节 管理层讨论与分析"章节 |
| `data/raw/firm_financial_panel.csv` | 公司-年度财务、治理与行业数据（4800 行） | 由 step0 生成；真实研究中对应 **CSMAR（国泰安）** 公司研究系列数据库 |
| `data/dictionary/myopia_dict.txt` | 43 个短期视域词词典 | 人工整理，理论来源见 docs/02；对照胡楠等（2021）43 词词典 |
| `data/dictionary/stopwords_cn.txt` | 通用中文停用词表 | 汇总整理自公开停用词表（哈工大停用词表、百度停用词表等） |
| `data/dictionary/stopwords_finance.txt` | 财经领域补充停用词 | 依据年报语料人工整理（"同比""报告期""证券代码"等） |
| `data/interim/*` | 中间产物（语料索引、分词结果、特征矩阵） | 由 step1—step3 生成，**不需要人工维护** |
| `data/processed/panel_measure.csv` | **测度结果表**（企业-年份面板，含最终变量） | 由 step4 生成，可直接导入 Stata / Python 回归 |
| `data/processed/validity_report.txt` | 信效度检验报告 | 由 step5 生成 |
| `data/processed/regression_results.md` | 回归结果汇总 | 由 step6 生成 |

## 3. 正式研究的数据源建议

| 数据类型 | 推荐来源 | 说明 |
|---|---|---|
| 年报文本（MD&A） | 巨潮资讯网（www.cninfo.com.cn） | 官方指定披露平台，PDF 可批量下载 |
| 公司财务数据 | CSMAR（国泰安） | 学术研究主流数据库，校内多有权限 |
| 公司治理数据 | CSMAR / CNRDS | 董事会、股权结构、审计意见等 |
| 行业分类与竞争度 | 证监会行业分类 / Wind | 用于计算赫芬达尔指数（HHI） |
| 专利与创新数据 | CNRDS / 国家知识产权局 | 用于稳健性检验（专利产出） |

## 4. 合规与留痕（写进论文"数据来源"小节的要点）

1. **来源标注**：数据来自哪个数据库 / 平台，抓取时间（精确到日）。
2. **授权与频率**：遵守目标网站 `robots` 协议，控制请求频率，避免高频抓取。
3. **样本口径**：明确纳入 / 剔除规则（如剔除金融业、ST 公司、上市不足一年、关键变量缺失）。
4. **去重与匹配**：统一公司代码（证券代码可能因更名、并购而变化），剔除重复观测。
5. **可复现**：保存原始文件与处理脚本，论文附录给出全部参数（分词模式、停用词表版本、词典来源）。

## 5. 免责声明

`data/raw/` 与 `data/processed/` 中的全部数据均为**教学演示用模拟数据**，
其中的"公司""行业""财务指标"等均为程序生成的虚构值，与任何真实企业无关，
